External Libraries:

Socket - this library was used for socket programming and core functionality of being about to send and receive packets as well as start the server

Instructions:

Have python3 installed

Please open terminal and navigate to the directory where the .py files are stored

Both programs run on localhost:8080/

To run the programs:

	-Type in python3 webserver.py to run part A
	-Type in python3 proxyserver.py to run part B
	-Open a browser, such as Firefox. Chrome can be a little buggy at times
	-Go to localhost:8080/<filename for part A, website link for part B>
	-The program will display the respective content
